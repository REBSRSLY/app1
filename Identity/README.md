# Identity — Vero Volley Milano

Cartella di identità visiva del club, costruita a partire dai materiali
reali già esistenti in `Volley graphic design/` (loghi ufficiali,
palette colori, campagna 2025/26) — **nessuna fotografia di atlete
usata o riprodotta**.

## Contenuto

| File | Cosa contiene |
|---|---|
| **`brand-guidelines.md`** | Il documento di riferimento: logo (versioni, area di rispetto, cosa non fare), palette colori con HEX, tipografia, motivi grafici, tono di voce. Parti da qui. |
| **`logo-presentation.html`** | Tavola visiva in stile "logo presentation" (Behance) — apri nel browser. Marchio, costruzione, colore, tipografia, motivi grafici, applicazioni (tag maglia, icona app, badge stagionale, tile social). |
| **`palette.svg`** | Tavola colori isolata, pronta per l'export. |
| **`patterns.svg`** | I tre motivi grafici (cucitura pallone, diagonale, mesh gradient) isolati. |

## Come aprire `logo-presentation.html`

È un file autosufficiente (font e immagini incorporati) — basta fare
doppio click e si apre nel browser predefinito, nessun server o
connessione richiesta.

## Il succo in tre righe

Blu Vero (`#1655A5`) e Rosso Volley (`#F3343D`) restano il cuore
dell'identità — sono già quelli in uso nella dashboard dello staff
tecnico. Il Magenta Numia (`#E0158C`), preso dalla campagna 2025/26, è
l'accento "energia": mai più del 5% di una composizione. Titoli in
Oswald Bold maiuscolo, testo in Roboto — la stessa famiglia già scelta
per i titoli dei grafici nella dashboard.
